## 📌 Project Overview

This project showcases a complete **end-to-end data analytics workflow** using the Google Play Store dataset. It highlights my ability to transform raw, unstructured data into meaningful insights and business-ready dashboards.

From **data cleaning in Excel** to **interactive dashboard development in Power BI**, this project demonstrates practical, job-ready skills relevant to real-world data analyst roles.

---

## 🎯 Business Problem

Mobile app marketplaces contain vast amounts of data, but extracting actionable insights can be challenging due to inconsistencies and data quality issues.

This project answers key business questions such as:

* What app categories perform best?
* What factors influence app ratings and installs?
* How do free vs paid apps compare?

## 🔧 Data Cleaning Process (Excel)

The dataset required significant preprocessing to ensure accuracy:

* Removed duplicate records to maintain data integrity
* Handled missing values in key columns (Ratings, Size, Android Version)
* Converted data types for proper analysis
* Cleaned and standardized categorical values
* Transformed "Installs" from text (e.g., "1,000+") into numeric format
* Standardized "Size" column (KB/MB normalization)
* Reformatted "Price" column into numeric values

---

## 📊 Data Modeling (Power BI)

* Imported cleaned dataset into Power BI
* Created calculated columns and measures using DAX
* Structured data for efficient visualization and filtering

## 📈 Dashboard Features

The interactive dashboard includes:

### 📌 KPI Metrics

* Total Number of Apps
* Average Rating
* Total Installs

### 📊 Visual Insights

* Apps by Category
* Installs by Category
* Ratings Distribution
* Free vs Paid Apps Comparison
* Top Apps by Installs

### 🎛️ Interactivity

* Dynamic filters (Category, Content Rating, App Type)
* Drill-down capability for deeper insights

---

## 🔍 Key Insights

* A small number of categories dominate the app market
* Free apps significantly outnumber paid apps
* High install counts do not always correlate with high ratings
* Certain categories consistently achieve better user satisfaction
